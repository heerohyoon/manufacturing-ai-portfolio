# 평가 계획서 (Pre-registration)

이 문서는 평가 데이터를 열기 전에 작성하고 커밋한다. 아래 규칙은 평가 데이터 결과를 본 뒤에 바꾸지 않는다.
바꿔야 할 일이 생기면 이 문서를 수정하는 대신 "변경 기록"에 이유와 함께 남긴다.

## 1. 데이터

- 시간순 정렬 후 앞 75%(1175행, 불량 80개)는 학습용, 뒤 25%(392행)는 평가용 (`src/data.py`)
- 평가 데이터는 `scripts/final_evaluation.py`에서만 연다. `tests/test_data.py`가 다른 곳의 호출을 막는다.

## 2. 전처리 (기준값은 모두 학습 데이터에서 계산)

| 단계 | 로지스틱 회귀 | LightGBM |
|---|---|---|
| 결측 지시자 | 학습 결측률 5% 이상 센서에 `<센서>_isna` 추가 (on/off는 4번에서 결정) | 같음 |
| 고결측 센서 | 학습 결측률 50% 초과 제거 | 같음 |
| 결측 대체 | 학습 중앙값 | 하지 않음 (모델이 직접 처리) |
| 상수 센서 | 학습 데이터에서 값이 하나뿐이면 제거 | 같음 |
| 극단값 | 학습 데이터 0.5% ~ 99.5% 분위수로 자르기 | 하지 않음 |
| 스케일 | 표준화 | 하지 않음 |

근거는 `notebooks/01_eda.ipynb`.

## 3. 모델과 후보 설정값

| 모델 | 고정 설정 | 후보 설정값 |
|---|---|---|
| 로지스틱 회귀 | L2, `class_weight="balanced"`, `max_iter=5000` | C ∈ {0.001, 0.01, 0.1, 1}, 결측 지시자 ∈ {off, on} |
| LightGBM | `n_estimators=300`, `learning_rate=0.03`, `num_leaves=8`, `min_child_samples=20`, `subsample=0.8`, `reg_lambda=1`, `class_weight="balanced"`, `random_state=42` | max_depth ∈ {2, 3}, colsample_bytree ∈ {0.1, 0.3}, 결측 지시자 ∈ {off, on} |

## 4. 설정값 선택

- 학습 데이터 안에서 `TimeSeriesSplit(n_splits=4)` 교차검증
- 기준: 4개 fold PR-AUC의 평균이 가장 높은 설정
- 두 모델은 각각 최적 설정을 고르고, **둘 다 평가 데이터에서 보고한다.** 평가 결과를 보고 한쪽을 고르지 않는다.

## 5. 판정 규칙

운영 가정: 라인에서 제품의 **20%**까지 추가 검사할 수 있다. 위험도가 높은 순으로 20%를 불량으로 판정한다.

이를 구현하는 두 방법 중 하나를 학습 데이터로 정한다.

- A. 고정 기준값: 학습 데이터 교차검증 예측(OOF)의 상위 20% 경계 확률값을 평가 데이터에 그대로 적용
- B. 묶음 내 할당량: 평가할 묶음 안에서 예측 확률 상위 20%를 판정 (정답 라벨은 쓰지 않음)

**결정 규칙**: 학습 데이터 교차검증의 fold 2~4 각각에 대해, 그 이전 fold들의 OOF 예측으로 A의 기준값을 구하고 해당 fold에 적용했을 때의 판정 비율을 잰다. 판정 비율이 20%에서 평균 5%p 넘게 벗어나면 B, 아니면 A를 쓴다. 두 모델에 각각 적용한다.

B를 쓰는 경우 평가 기간 전체(392행)를 한 묶음으로 본다.

## 6. 보고할 지표

| 구분 | 지표 |
|---|---|
| 주 지표 | PR-AUC, 5번 규칙에서의 불량 재현율 |
| 함께 보고 | 정밀도, 혼동행렬, ROC-AUC, 누적 이득 곡선 (검사 비율 10/20/30/50%) |
| 참고 | 정확도 |
| 기준선 | 무작위: PR-AUC = 평가 데이터 불량 비율, 20% 검사 재현율 = 20% |

## 7. 불확실성

- 평가 데이터를 2000번 복원추출(seed 0)해 95% 백분위 구간을 구한다: PR-AUC, 20% 검사 재현율
- 두 모델의 PR-AUC 차이(로지스틱 - LightGBM)도 같은 표본으로 구간을 구한다
- 해석: 구간 하한이 무작위 기준선보다 위일 때만 "무작위보다 낫다"고 쓴다. 차이 구간이 0을 포함하면 "우열을 단정할 수 없다"고 쓴다.

## 8. 최종 평가 이후에 하는 분석 (결과로 결정을 바꾸지 않음)

- 무작위 분할과의 비교: 같은 설정으로 전체 데이터를 층화 무작위 분할(25%, seed 0~4)했을 때의 PR-AUC
- SHAP: 학습 데이터로 학습한 두 모델을 학습 데이터에서 해석한다. |r| > 0.95인 센서는 같은 그룹으로 묶어 보고한다. 결과는 원인이 아니라 점검 후보로 다룬다.

## 9. 사전 지식 공개

1차 작업(`archive/v1`)에서 같은 평가 데이터의 결과를 이미 봤다. 그때 알게 된 것은 다음과 같다.

- 같은 설정값 후보에서 로지스틱 회귀가 LightGBM보다 평가 데이터 점수가 높았다
- 고정 기준값이 평가 기간에 판정 비율을 크게 낮췄다
- 평가 기간에 센서 오류값이 있었다

이 지식이 결정에 끼칠 수 있는 영향을 줄이기 위해, 3번 후보 설정값은 1차와 같게 두었고(결과를 보고 고치지 않음), 5번 판정 방식과 결측 지시자 사용 여부는 학습 데이터 규칙으로 정한다. 극단값 처리는 학습 데이터에서도 같은 현상이 확인되어 넣었다(EDA 5절). 다만 처리 방식을 최솟값~최댓값에서 분위수로 바꾼 것은 학습 데이터 안의 9998 값 때문이다.
